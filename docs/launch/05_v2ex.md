**标题：** 做了个开源 PR 验证工具 CodeGuard：让 7B 模型选证据 ID，而不是自己编文件和行号

**正文：**

做 CodeGuard 的真实 PR 测试时，我发现本地 `qwen2.5-coder:7b` 能看出 shell 执行风险和测试回归，但自由生成的文件、行号、规则引用有时不准。所以没有直接换更大的模型，而是改了系统边界：

1. 固定 GitHub PR 的 BASE/HEAD commit，在两个版本上分别跑 Ruff、Bandit 和 Docker 隔离的 pytest；BASE 通过、HEAD 失败才算引入回归。
2. 把 diff、静态结果和测试结果收进确定性的 Evidence Registry，生成 ID。
3. LLM 的结构化输出只选择 `evidence_ids`；最终 file/line/rule/test 信息由程序解析，不接受不存在的 ID。无法确定源码行时保留测试级证据。

目前用公开的 demo 仓库验证了两个受控 PR：干净 PR 产生 0 个 finding，故意出错的 PR 检出了预期的安全和回归类别，最终 2/2 finding 完成 grounding。这不是统计 benchmark，仍需要更多仓库和模型验证。项目定位是辅助 review，不会自动修代码。

源码、架构和 Quick Start：https://github.com/shuhanzhou01-stack/codeguard

Demo PR：https://github.com/shuhanzhou01-stack/codeguard-demo
